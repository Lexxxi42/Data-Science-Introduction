# Введение в Python: навыки объектно-ориентированного программирования

> Этот проект направлен на освоение основ объектно-ориентированного программирования в Python.
> Задания построены последовательно. От создания простого класса до реализации логирования и интеграции с внешними сервисами.

| Упражнение | О чем | Описание |
|---|---------|-------------|
| 00 | Простые классы | Создать класс Must_read, который читает и выводит содержимое файла data.csv.<br>Цель: первое знакомство с классами. |
| 01 | Методы классов | Перенести логику чтения файла в метод file_reader() класса Research.<br>Цель: понять разницу между классом и методом. |
| 02 | Конструктор | Добавить конструктор __init__(), принимающий путь к файлу. Реализовать проверку структуры файла.<br>Цель: научиться использовать конструкторы и обрабатывать ошибки. |
| 03 | Вложенные классы | Добавить вложенный класс Calculations с методами counts() и fractions().<br>Цель: структурировать код с помощью вложенных классов. |
| 04 | Наследование | Создать класс Analytics, унаследованный от Calculations. Добавить методы predict_random() и predict_last().<br>Цель: освоить наследование и расширение функциональности. |
| 05 | Декомпозиция | Разделить код на три файла: <ul><li>config.py: параметры и шаблон отчёта</li><li>analytics.py: основная логика</li><li>make_report.py: точка входа, формирующая текстовый отчёт</li></ul>Цель: научиться модульной организации проекта и работе с конфигурацией. |
| 06 | Логирование | Добавить логирование всех методов в файл analytics.log. Реализовать отправку уведомления в Telegram.<br>Цель: освоить логирование и интеграцию с внешними API. |

## Запуск
```bash
# Для упражнений 02–06
python3 first_constructor.py data.csv

# Для упражнений 05–06
python3 make_report.py data.csv
