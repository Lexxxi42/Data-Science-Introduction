# Introduction to Machine Learning: Advanced Tasks

> This project aims to explore advanced machine learning techniques using the scikit-learn library. The tasks range from learning about regularization and hyperparameter tuning to creating ensembles and organizing code into an OOP-based pipeline structure.

## Project Content

| Exercise | Topic | Description |
|------------|------|----------|
| 00 | Regularization | Researching the impact of regularization on logistic regression, SVM, decision tree, and random forest models. Comparing L1 and L2 regularization, and selecting parameters that affect overfitting. |
| 01 | GridSearch | Selecting hyperparameters for SVM, decision tree, and random forest using GridSearchCV. Comparing results and finding optimal parameter combinations. |
| 02 | Metrics | Calculating accuracy, precision, recall, and ROC AUC for the best models. Analyzing model errors by day of the week, lab, and user. |
| 03 | Ensembles | Implementing Voting, Bagging, and Stacking classifiers. Comparing their performance with individual models. |
| 04 | Pipelines and OOP | Creating structured code using custom transformers, pipelines, and classes to automate the process of training and evaluating models. |
