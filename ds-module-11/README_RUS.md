# Введение в машинное обучение: продвинутые задачи

> Этот проект направлен на освоение продвинутых техник машинного обучения с использованием библиотеки scikit-learn. Задания построены от изучения регуляризации и подбора гиперпараметров до создания ансамблей и организации кода в структуру на основе ООП и пайплайнов.

## Содержание проекта

| Упражнение | Тема | Описание |
|------------|------|----------|
| 00 | Регуляризация | Исследование влияния регуляризации на модели логистической регрессии, SVM, деревьев решений и случайного леса. Сравнение L1 и L2 регуляризации, подбор параметров, влияющих на переобучение. |
| 01 | GridSearch | Подбор гиперпараметров для SVM, дерева решений и случайного леса с помощью GridSearchCV. Сравнение результатов и поиск оптимальных комбинаций параметров. |
| 02 | Метрики | Вычисление accuracy, precision, recall и ROC AUC для лучших моделей. Анализ ошибок модели по дням недели, лабораторным работам и пользователям. |
| 03 | Ансамбли | Реализация Voting, Bagging и Stacking классификаторов. Сравнение их эффективности с индивидуальными моделями. |
| 04 | Пайплайны и ООП | Создание структурированного кода с использованием кастомных трансформеров, пайплайнов и классов для автоматизации процесса обучения и оценки моделей. |
